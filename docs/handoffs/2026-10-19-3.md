## Current state

- Spike answers: `adb push` into the app folder works on API 36; `asset://`
  glyphs load on MapLibre 13.7.1; the glyph fonts are OFL.
- Test region: Roberts Creek and Largo Road, 1.4 MB, built in 30 s from the BC
  extract. Files were in `~/tiles-work` (pmtiles CLI, planetiler.jar, the BC
  extract, `roberts-creek.pmtiles`, `stock.pmtiles`). Rebuild with
  `tools/tiles/build-region.sh`.
- After changing regions the map reloads when the Regions screen closes.
  Copying a file with adb while the app is on the map needs a visit to Regions
  and back.
- GPX import: SAX parser, routes become tracks, waypoints ignored, 500,000 point
  limit, time 0 means unknown (export leaves it out). Imported tracks are
  ordinary tracks with no marker.
- Known limits: the emulator test only used a basic GPX (no routes, DOCTYPE or
  odd encodings on a device); trail colours for difficulty were seen on the
  map but not checked against real tagged trails; `INTERNET` permission is
  still declared; no launcher icon; battery-optimisation hint not built.
- Not tried: airplane mode on the emulator (the style has no network URLs and
  the log showed no tile requests after the change, but it was not forced).
